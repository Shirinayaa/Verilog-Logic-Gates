# Verilog Logic Gates

## Overview

This repository contains the implementation of fundamental digital logic gates using Verilog HDL. Each gate is designed, simulated, and verified individually to build a strong foundation in digital design and hardware description languages.

## Implemented Gates

- AND Gate
- OR Gate
- NOT Gate
- NAND Gate
- NOR Gate
- XOR Gate
- XNOR Gate

## Repository Structure

Each gate is organized in a separate folder containing:

- Verilog source code
- Testbench
- Simulation waveform
- RTL schematic
- Individual README with theory and implementation details

## Tools Used

- Verilog HDL
- Visual Studio Code
- Icarus Verilog
- GTKWave
- AMD Vivado 2025.1

## Concepts Covered

- Verilog module structure
- Input and output ports
- Continuous assignment (`assign`)
- Dataflow modeling
- Combinational logic
- Testbench development
- Functional simulation
- RTL schematic generation

## Purpose

This repository serves as the foundation for learning digital design using Verilog and is the first step toward implementing more complex digital circuits such as adders, multiplexers, decoders, flip-flops, counters, finite state machines, and FPGA-based designs.
